## Project Context
This is an interactive 3D WebGL display simulation built with React, Three.js, Tailwind CSS, and Web Audio API.
It demonstrates the technical journey from UI code to microscopic OLED subpixel photon emission:
1. 3D Exploded Layer Architecture (Sapphire Glass, Composite UI, GPU Raster Paint, DOM Layout Box Model, OLED Subpixels, Titanium Chassis).
2. Microscopic 1000x Deep Zoom into Diamond Pentile OLED subpixel matrix.
3. Photonic RGB Light Lab (Additive Color Synthesis & Human Eye Perception).
4. Sinuous Photonic Light Ribbon Wave (Epic-style fiber-optic wave).
5. 45-Second Guided Pitch Tour for judges.

## Tech Stack
- Frontend: React 18, TypeScript, Vite, Tailwind CSS, Lucide React
- 3D Engine: Three.js (WebGL 2.0, Custom Shaders, Iridescent Holographic Foil)
- Audio: Web Audio API Procedural Synthesizer
